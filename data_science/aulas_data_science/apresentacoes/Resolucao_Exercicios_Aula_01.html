Exercício 1 · Temperatura

Os registros são horários e temperaturas medidas em uma máquina. O gráfico de linhas permite acompanhar a variação ao longo do dia.

Código

import pandas as pd
import matplotlib.pyplot as plt

dados = {
    "tempo": ["08:00", "09:00", "10:00", "11:00", "12:00",
              "13:00", "14:00", "15:00", "16:00", "17:00"],
    "temperatura": [25, 28, 32, 35, 38, 42, 45, 41, 37, 33]
}

df = pd.DataFrame(dados)
df["variacao"] = df["temperatura"].diff()

ax = df.plot(x="tempo", y="temperatura", kind="line", marker="o",
             legend=False, title="Temperatura da máquina ao longo do tempo")
ax.set_xlabel("Horário")
ax.set_ylabel("Temperatura (°C)")
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

print("Maior temperatura:", df["temperatura"].max(), "°C")
print("Menor temperatura:", df["temperatura"].min(), "°C")
print("Temperatura média:", df["temperatura"].mean(), "°C")
print("Maior elevação por intervalo:", df["variacao"].max(), "°C")
print(df.loc[df["variacao"] == df["variacao"].max(), ["tempo", "variacao"]])

Respostas

a) Maior temperatura: 45 °C, às 14:00.
b) Menor temperatura: 25 °C, às 08:00.
c) Maior elevação: 4 °C. Ocorreu em dois intervalos: das 09:00 às 10:00 (28 °C para 32 °C) e das 12:00 às 13:00 (38 °C para 42 °C).
d) Temperatura média: df["temperatura"].mean() resulta em 35,6 °C.

O método diff() calcula a diferença entre cada leitura e a leitura anterior; por isso, o primeiro registro não tem variação definida.

Exercício 2 · Vendas por setor

O faturamento por setor é obtido somando as vendas de todos os clientes daquele setor. Também é possível calcular a média e localizar a maior venda individual.

Código

import pandas as pd
import matplotlib.pyplot as plt

dados = {
    "cliente": ["C1", "C2", "C3", "C4", "C5", "C6", "C7", "C8", "C9", "C10"],
    "setor": ["Tecnologia", "Indústria", "Comércio", "Tecnologia", "Indústria",
              "Comércio", "Tecnologia", "Indústria", "Comércio", "Tecnologia"],
    "vendas": [1500, 2500, 1200, 3000, 4500, 2000, 3500, 5000, 2800, 4000]
}

df = pd.DataFrame(dados)
faturamento_setor = df.groupby("setor")["vendas"].sum()
media_setor = df.groupby("setor")["vendas"].mean()
maior_venda = df.loc[df["vendas"].idxmax()]

ax = faturamento_setor.plot(kind="bar", color="#33766a",
                            title="Faturamento total por setor")
ax.set_xlabel("Setor")
ax.set_ylabel("Faturamento (R$)")
plt.xticks(rotation=0)
plt.tight_layout()
plt.show()

print("Faturamento por setor:\n", faturamento_setor)
print("Média de vendas por setor:\n", media_setor)
print("Faturamento total:", df["vendas"].sum())
print("Maior venda:\n", maior_venda)

Resultados

b) Menor faturamento: Comércio, com R$ 6.000.
c) Maior compra: cliente C8, do setor Indústria, com R$ 5.000.
d) Faturamento total: df["vendas"].sum() resulta em R$ 30.000.
e) Média por setor: df.groupby("setor")["vendas"].mean(). Os resultados são Tecnologia: R$ 3.000; Indústria: R$ 4.000; Comércio: R$ 2.000.

Exercício 3 · Preços das ações

Os preços de fechamento são organizados por dia e exibidos em um gráfico de linhas. Comparando cada preço com o do dia anterior, identificamos as quedas.

Código

import pandas as pd
import matplotlib.pyplot as plt

dados = {
    "dia": ["D1", "D2", "D3", "D4", "D5", "D6", "D7", "D8", "D9", "D10"],
    "preco": [25.50, 26.20, 25.80, 27.00, 28.50,
              27.80, 29.20, 30.50, 29.80, 31.00]
}

df = pd.DataFrame(dados)
df["variacao"] = df["preco"].diff()

ax = df.plot(x="dia", y="preco", kind="line", marker="o", legend=False,
             title="Preço de fechamento ao longo de 10 dias")
ax.set_xlabel("Dia")
ax.set_ylabel("Preço (R$)")
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

print("Maior preço:", df["preco"].max())
print("Menor preço:", df["preco"].min())
print("Média dos preços:", df["preco"].mean())
print("Dias com queda:\n", df.loc[df["variacao"] < 0, ["dia", "preco", "variacao"]])
lucro = (df["preco"].iloc[-1] - df["preco"].iloc[0]) * 100
print("Lucro com 100 ações: R$", lucro)

Respostas

a) Maior preço: R$ 31,00, no dia D10.
b) Menor preço: R$ 25,50, no dia D1.
c) Dias com queda: D3 (de R$ 26,20 para R$ 25,80), D6 (de R$ 28,50 para R$ 27,80) e D9 (de R$ 30,50 para R$ 29,80).
d) Média dos preços: R$ 28,13.
e) Lucro bruto: (R$ 31,00 − R$ 25,50) × 100 = R$ 550,00, desconsiderando taxas e impostos.
Resolução baseada nos dados apresentados no material da aula.
